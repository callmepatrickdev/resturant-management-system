# 🍽️ Restaurant Management System

A Java console-based restaurant management system for managing tables, menu items, and customer tickets.

This project was created to practice **Java and Object-Oriented Programming (OOP)** concepts.

## 🛠️ Technologies

- Java
- OOP
- ArrayList & List
- Exception Handling
- Git & GitHub
- Eclipse IDE


## 📦 Package

```java
package restaurant;
```

## 🧩 Main Classes

- **Main** – Starts the application.
- **Restaurant** – Manages tables, menu items, and tickets.
- **Table** – Represents restaurant tables and seating capacity.
- **MenuItem** – Represents menu items and prices.
- **Ticket** – Represents customer orders.
